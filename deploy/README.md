# UT 페이지 외부 공개하기 — GitHub Pages + 구글 시트

진행자 PC 를 켜 두지 않아도 참가자가 **링크 하나로** 테스트에 참여하고, 응답은 진행자의 구글 시트에 쌓이게 하는 방법입니다.

| | 지금 (localhost:8780) | 여기서 만드는 것 |
| --- | --- | --- |
| 참가자 접속 | 같은 네트워크 안에서만 | **어디서든 링크로** |
| 진행자 PC | 켜 둬야 함 | **꺼져 있어도 됨** |
| Figma 프로토타입 | 보임 | **그대로 보임** |
| 응답 저장 위치 | `ut/data/responses.json` | **구글 시트** |
| 비용 | 없음 | 없음 |

> **지금 쓰시던 localhost:8780 은 그대로 둡니다.** 설정을 비워 두면 예전과 똑같이 동작하고,
> 여기서 만드는 건 그 옆에 하나 더 두는 것입니다. 대면 UT 는 localhost, 원격은 공개 링크로 나눠 쓰셔도 됩니다.

---

## 순서

1. 응답 저장소 만들기 (구글 시트 + Apps Script) — 약 5분
2. 주소를 설정에 넣기 — 1분
3. GitHub 에 올리고 Pages 켜기 — 약 5분

---

## 1. 응답 저장소 만들기

### 1-1. 시트 만들기

<https://sheets.new> 를 열어 새 스프레드시트를 만들고, 이름을 `당근 UT 응답` 처럼 알아보기 쉽게 바꿉니다.
시트 안에는 아무것도 입력하지 않아도 됩니다. 칸은 스크립트가 알아서 만듭니다.

### 1-2. 스크립트 붙여넣기

같은 시트에서 **확장 프로그램 → Apps Script** 를 엽니다.
기본으로 들어 있는 `function myFunction() {}` 를 모두 지우고, 이 저장소의 **`deploy/apps-script.gs`** 내용을 통째로 붙여넣습니다.

맨 위에 비밀번호가 있습니다. 바꾸시려면 여기만 고치면 됩니다.

```javascript
const PASSCODE = 'daangn-ut-2026';
```

> 이 비밀번호는 **스크립트 안에만** 있습니다. 공개되는 페이지 소스에는 들어가지 않습니다.
> 진행자가 대시보드에서 입력한 값이 여기로 와서 대조되는 구조라, 참가자는 제출만 되고 열람은 안 됩니다.

저장(💾)합니다.

### 1-3. 웹앱으로 배포

오른쪽 위 **배포 → 새 배포** 를 누릅니다.

| 항목 | 선택할 값 |
| --- | --- |
| 유형 (톱니바퀴 아이콘) | **웹 앱** |
| 설명 | 아무거나 (예: `v1`) |
| 다음 사용자로 실행 | **나** |
| 액세스 권한이 있는 사용자 | **모든 사용자** |

> "모든 사용자" 가 맞습니다. 참가자가 구글 로그인 없이 응답을 제출해야 하기 때문입니다.
> 응답을 **읽는 것**은 비밀번호로 막혀 있으니, 주소를 아는 사람이 남의 응답을 볼 수는 없습니다.

**배포**를 누르면 권한 승인을 한 번 요구합니다. "고급 → (프로젝트 이름)(으)로 이동 → 허용" 으로 진행하세요.
자기가 만든 스크립트에 자기 시트 접근을 허락하는 절차입니다.

끝나면 **웹 앱 URL** 이 나옵니다. 이렇게 생겼습니다.

```
https://script.google.com/macros/s/AKfycb................/exec
```

이 주소를 복사해 둡니다.

### 1-4. 잘 되는지 확인

복사한 주소 뒤에 `?op=ping` 을 붙여 브라우저로 열어 보세요.

```
https://script.google.com/macros/s/AKfycb................/exec?op=ping
```

이렇게 나오면 성공입니다.

```json
{"ok":true,"service":"daangn-ut"}
```

## 2. 주소를 설정에 넣기

`ut/js/config.js` 를 열어 **딱 한 줄**만 고칩니다.

```javascript
const RESPONSE_ENDPOINT = 'https://script.google.com/macros/s/AKfycb................/exec';
```

그다음 배포 폴더를 다시 만듭니다.

```bash
node deploy/build-pages.js
```

`docs/` 폴더가 새로 만들어지고, 마지막 줄에 넣은 주소가 찍히면 제대로 들어간 것입니다.

> **주의** — 이 줄을 채우면 `localhost:8780` 도 구글 시트를 쓰게 됩니다.
> localhost 는 예전처럼 로컬 파일에 저장하고 싶으시면, 이 줄은 비워 두고
> `docs/js/config.js` 쪽만 주소를 넣으셔도 됩니다(`build-pages.js` 를 다시 돌리면 덮어쓰이니 주의).

## 3. GitHub 에 올리기

### 3-1. 저장소 만들기

<https://github.com/new> 에서 저장소를 하나 만듭니다. 이름은 예를 들어 `daangn-ut`.
공개(Public)로 만드세요 — 무료 플랜에서 GitHub Pages 는 공개 저장소에서만 됩니다.

### 3-2. 올리기

프로젝트 폴더에서 아래를 차례로 실행합니다. `<주소>` 자리에는 방금 만든 저장소 주소를 넣으세요.

```bash
git init
git add .
git commit -m "당근 앱 리디자인 UT 페이지"
git branch -M main
git remote add origin <주소>
git push -u origin main
```

### 3-3. Pages 켜기

저장소 페이지에서 **Settings → Pages** 로 갑니다.

| 항목 | 선택할 값 |
| --- | --- |
| Source | Deploy from a branch |
| Branch | `main` / **`/docs`** |

저장하고 1~2분 기다리면 주소가 나옵니다.

```
https://<계정이름>.github.io/daangn-ut/
```

- 참가자 화면 — `https://<계정이름>.github.io/daangn-ut/`
- 결과 대시보드 — `https://<계정이름>.github.io/daangn-ut/#/result`

## 확인할 것

- [ ] 참가자 화면이 **다른 기기**(휴대폰 등)에서도 열린다
- [ ] 오른쪽에 Figma 프로토타입이 뜬다
- [ ] 상단에 빨간 `응답 수집 서버 꺼짐` 배지가 **없다** (있으면 2번 주소가 잘못된 것)
- [ ] 설문을 끝까지 넘기면 "응답이 저장되었습니다" 가 뜬다
- [ ] 구글 시트에 줄이 하나 늘어난다
- [ ] `#/result` 에서 비밀번호를 넣으면 그 응답이 보인다

## 알고 계셔야 할 것

**페이지가 공개됩니다.** 주소를 아는 사람은 누구나 열 수 있고, 저장소 소스도 볼 수 있습니다.
Figma 프로토타입 링크도 소스에 들어 있으니, 프로토타입을 공개하기 곤란하면 이 방법은 쓰지 마세요.

**제출은 누구나 할 수 있습니다.** 주소를 아는 사람은 응답을 넣을 수 있습니다.
장난 응답이 들어오면 구글 시트에서 그 줄을 직접 지우면 됩니다.

**응답 열람만 비밀번호로 막혀 있습니다.** 대시보드와 전체 삭제가 여기 해당합니다.

**수집된 응답(`ut/data/`)은 저장소에 올라가지 않습니다.** `build-pages.js` 가 `docs/` 에 복사하지 않고,
`.gitignore` 로도 막아 두었습니다. 공개 저장소에 참가자 응답이 올라가는 사고를 막기 위한 것입니다.

**고친 내용을 반영하려면** `node deploy/build-pages.js` 를 다시 돌리고 커밋·푸시하면 됩니다.
Figma 프로토타입만 고친 경우에는 페이지를 새로고침하기만 하면 되고, 다시 올릴 필요가 없습니다.
