# B. 최종 문항 (20블록 · 10~15분)

## 시작

### 1. 나의 당근 화면, 같이 살펴봐 주세요 `안내`

- 이번 테스트에서는 ‘채팅’ 탭과 ‘나의 당근’ 탭의 사용성만 확인합니다.
- 기존 화면과 개선 후 화면을 차례로 써 보시고, 느낀 점을 알려주세요.
- 몇 가지 Task와 함께 작업마다 짧은 질문을 드려요. 테스트는 약 10분~15분 정도 걸립니다.
- 평가 대상은 참여자분이 아니라 화면입니다. 막히는 지점이 있다면 그게 가장 중요한 정보예요.
- 버튼: 시작하기

### 2. 당근을 얼마나 자주 쓰시나요? `단일선택` **필수**

- 보기: 거의 매일 / 일주일에 몇 번 / 한 달에 몇 번 / 그보다 드물게
- 저장 키: `participant`

## 개선 전 (AS-IS)

### 3. 개선 전 화면으로 작업을 해볼게요 `안내`

- 오른쪽에 화면이 준비되어 있어요. 작업이 시작되면 직접 눌러 가며 사용하실 수 있습니다.
- 정답을 맞히는 시험이 아니라 화면을 평가하는 자리예요. 헤매셔도 괜찮습니다.
- 버튼: 첫 번째 작업 시작

### 4. 판매 중인 물건 확인하기 `프로토타입 작업` **필수**

- 지금 판매 중인 물건이 몇 개인지 확인할 수 있는 화면까지 이동해 주세요.
- 작업 직후 난이도(SEQ): 1~7점 · 매우 어려웠다 ↔ 매우 쉬웠다 → 같은 화면에서 이어서 응답
- 저장 키: `asis-t1` / `asis-t1-seq`

### 5. 구매한 물건의 거래 상태 확인하기 `프로토타입 작업` **필수**

- 최근에 구매한 물건이 어떤 상태인지 확인할 수 있는 화면까지 이동해 주세요.
- 저장 키: `asis-t2` / `asis-t2-seq`

### 6. 관심 목록 다시 찾기 `프로토타입 작업` **필수**

- 예전에 하트를 눌러 둔 물건들을 모아 볼 수 있는 화면까지 이동해 주세요.
- 저장 키: `asis-t3` / `asis-t3-seq`

### 7. 개선 전 화면에서 원하는 정보를 찾기가 얼마나 쉬웠나요? `척도` **필수**

- 1~5점 · 매우 어려웠다 ↔ 매우 쉬웠다
- 저장 키: `asis-findability`

### 8. 개선 전 화면에서 불편하거나 헷갈렸던 점을 알려 주세요. `주관식`

- 떠오르는 대로 편하게 적어 주세요. 한 줄이어도 괜찮아요.
- 저장 키: `asis-open`

## 개선 후 (TO-BE)

### 9. 개선 후 화면으로 작업을 해볼게요 `안내`

### 10~12. 같은 작업 3개 `프로토타입 작업` **필수**

- 판매 중인 물건 확인하기 / 구매한 물건의 거래 상태 확인하기 / 관심 목록 다시 찾기
- 각 작업 카드 안에서 난이도(SEQ)까지 응답
- 저장 키: `tobe-t1` `tobe-t2` `tobe-t3` / `tobe-t1-seq` `tobe-t2-seq` `tobe-t3-seq`

### 13. 개선 후 화면에서 원하는 정보를 찾기가 얼마나 쉬웠나요? `척도` **필수**

- 1~5점 · 저장 키: `tobe-findability`

### 14. 개선 후 화면에서 좋았던 점이나 여전히 아쉬운 점을 알려 주세요. `주관식`

- 저장 키: `tobe-open`

## 비교

### 15. 두 화면 중 어느 쪽이 더 쓰기 편했나요? `비교선택` **필수**

- 보기: 첫 번째 화면(개선 전) / 두 번째 화면(개선 후)
- 저장 키: `compare-pref`

### 16. 그렇게 고른 이유를 알려 주세요. `주관식` **필수**

- 저장 키: `compare-why`

### 17. 개선된 화면이라면, 거래를 확인한 뒤에도 당근을 더 둘러보게 될 것 같나요? `척도` **필수**

- 1~5점 · 전혀 아니다 ↔ 매우 그렇다
- 저장 키: `revisit`

### 18. 개선안에서 아직 더 손봐야 할 것 같은 부분이 있다면 골라 주세요. `복수선택`

- 보기: 판매·구매·관심 등 거래 영역 / 나의 활동 요약 / 지역생활 서비스 진입 / 커뮤니티 진입 / 설정·고객지원 / 특별히 없음
- 저장 키: `improve-area`

## SUS

### 19. 개선 후 화면에 대해 얼마나 그렇다고 느끼시나요? `표(행렬)` **필수**

- 오른쪽에 개선 후 화면을 다시 띄워 두었어요. 직접 보면서 답해 주세요.
- 깊게 고민하지 마시고 첫 느낌대로 골라 주세요. 비슷해 보이는 문장이 반복되지만 의도된 구성입니다.
- 척도: 1~5점 · 전혀 그렇지 않다 ↔ 매우 그렇다

| # | 문항 | 저장 키 |
|---:|---|---|
| 1 | 개선 후 화면을 자주 사용하고 싶다. | `sus-1` |
| 2 | 개선 후 화면은 불필요하게 복잡하다. | `sus-2` |
| 3 | 개선 후 화면은 사용하기 쉬웠다. | `sus-3` |
| 4 | 개선 후 화면을 쓰려면 누군가의 도움이 필요할 것 같다. | `sus-4` |
| 5 | 개선 후 화면의 기능들이 서로 잘 연결되어 있다. | `sus-5` |
| 6 | 개선 후 화면에는 앞뒤가 맞지 않는 부분이 많다. | `sus-6` |
| 7 | 대부분의 사람이 개선 후 화면을 금방 익힐 수 있을 것 같다. | `sus-7` |
| 8 | 개선 후 화면은 쓰기에 번거롭다. | `sus-8` |
| 9 | 개선 후 화면을 쓰는 동안 헤매지 않고 자신 있게 움직였다. | `sus-9` |
| 10 | 개선 후 화면을 쓰기 전에 익혀야 할 것이 많을 것 같다. | `sus-10` |

> 점수 = (홀수 합 − 10 + 50 − 짝수 합) × 2.5, 0~100점. 68점이 평균입니다.

# C. 변경 대조표

| 항목 | 기존 | 최종 | 이유 |
|---|---|---|---|
| 전체 블록 | 37 | **20** | 10~15분 안에 끝나도록 |
| 작업 직후 난이도(SEQ) | 별도 화면 6개 | **작업 카드 안**으로 | 기억이 가장 선명한 직후에 묻는 쪽이 측정에도 유리 |
| SUS | 화면 10개 + 안내 1개 | **한 화면의 표** | SUS 는 원래 한 장으로 받는 설문 |
| 주 사용 목적 | 있음 | **삭제** | 블록 예산. 필요하면 되살릴 수 있음 |
| SUS 문항 주어 | "이 화면" | **"개선 후 화면"** | 어느 화면을 묻는지 불명확했음 |
| 재방문 의향 설명 | "PRD 의 Primary KPI…" | **삭제** | 참가자에게 내부 지표를 보일 이유 없음 |
| findability 문항 | "이 화면에서…" | **"개선 전/개선 후 화면에서…"** | 위와 같은 이유 |
| 첫 화면 문구 | 기존 안내문 | **새 문구** | 요청대로 교체 |

**저장 키는 하나도 바뀌지 않았습니다.** 태스크 성공률 · 소요시간 · SEQ · 정보 탐색 용이성 ·
선호도 · 재방문 의향 · SUS 모두 대시보드에서 전과 같이 집계됩니다.

    { value: 'buy', label: '중고 물건 구매' },
    { value: 'community', label: '동네생활·모임 참여' },
    { value: 'local', label: '알바·부동산·중고차 등 지역생활 서비스' },
